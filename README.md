# 📖 Zara-Chabby

> **A digital reading experience for *Thus Spoke Zara-Chabby*.**

Zara-Chabby is a modern web application designed to bring *Thus Spoke Zara-Chabby* to readers through an interactive online reading platform.

The project is being developed with **React.js and TypeScript**, with the goal of creating a clean, responsive, and immersive reading experience across desktop, tablet, and mobile devices.

---

## ✨ Features

### 📚 Online Book Reader

* Read *Thus Spoke Zara-Chabby* directly from the website.
* Browse the book chapter by chapter.
* Navigate between previous and next chapters.
* Organized according to the structure of the original book.
* Responsive reading experience for different screen sizes.

### 👤 Reader Accounts

The platform is designed to allow readers to create personal accounts.

Planned functionality includes:

* User registration
* Login and logout
* Secure user sessions
* Individual reader profiles
* Tracking of reader activity

### 📊 Reading Progress

Each reader will be able to keep track of their progress through the book.

Planned features include:

* Mark chapters as read
* Save reading progress
* Continue from the last chapter
* Reading progress percentage
* Personal reading history

### 🔖 Future Reader Features

The platform may also include:

* Bookmarks
* Search
* Adjustable font size
* Dark and light reading modes
* Reading time estimates
* Notes
* Chapter navigation
* Resume reading

# 🚀 Getting Started

## Prerequisites

Make sure you have the following installed:

* **Node.js**
* **npm**
* **Git**

You can check your Node.js and npm versions with:

```bash
node -v
npm -v
```

---

## 📥 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Move into the project directory:

```bash
cd zara-chabby
```

Install the project dependencies:

```bash
npm install
```

---

## ▶️ Running the Development Server

Start the development server:

```bash
npm run dev
```

Vite will provide a local development URL, usually:

```text
http://localhost:5173
```

Open the URL in your browser to view the application.
